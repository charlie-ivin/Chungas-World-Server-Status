ATTRACTIONS

Icons: put image files in the cw-icons folder of this repo (e.g. cw-icons/the-swan-pub.png) and type the file name (no extension) in Icon.

CHUNGAS WORLD LINKS

These are the "EXPLORE CHUNGAS WORLD" buttons on the home page. Edit the text, change where a button goes, reorder with ↑ ↓, or delete what you don't want. In Link you can type a page of the main site like /coasters-park or a full address like https://example.com. A section with no buttons is hidden. A live preview is at the bottom of this page. Changes go live when you press Save changes to GitHub.

SAVE

Changes stay local until you save. This commits (home page, attractions and links) to and creates an embed page (embed/<id>.html) for any new attraction.
